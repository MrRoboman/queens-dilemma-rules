# ⚠️ Spoilers: Campaign Rules Revealed So Far

Content our group has revealed during the campaign that affects the rules. It adds to the core rulebook ([`RULES.md`](../RULES.md)). Where a component here conflicts with the rulebook, **the component wins** ([p. 42](https://mrroboman.github.io/queens-dilemma-rules/?page=42), [p. 45](https://mrroboman.github.io/queens-dilemma-rules/?page=45)).

Conventions:
- Card text is transcribed **word for word** in quotes. Icons use the symbols from the glossary in `RULES.md`: √ Hegemony, ∑ Independence, † Infamy, ∆ Power, º Gold, ª Materials, Ƒ Food, ∞ Army.
- Text that couldn't be read is marked **[unreadable]**.
- "Game N" is the Timeline game number in which the component was revealed.
- **Status** is Active, In deck (unlocked but not currently in play) or Trashed. Trashed components no longer apply but stay listed for history.
